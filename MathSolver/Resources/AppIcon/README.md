# Math Solver branding

Approved mark: open book with custom M (Math) and brain. Brand blue: #2563EB.

- Canonical symbol: ../Images/mathsolver_logo.svg.
- Reversed: mathsolver_logo_light.svg.
- Small header cut: mathsolver_logo_small.svg / mathsolver_logo_small_light.svg; same silhouette and M, slightly wider central brain fold.
- appicon.svg is the solid brand-blue background; MauiIcon composites the reversed symbol. Android foreground scale leaves room for launcher masks.
- Native splash uses ../Splash/mathsolver_splash.svg (a separate resource basename to avoid Android collisions); the Windows in-app splash uses the reversed UI symbol on the same brand blue.
- Shell and About select blue/white artwork for light/dark themes.
- Source PNG and manual Windows ICO are intentionally absent. MAUI Resizetizer generates PNG platform resources and the Windows ICO; XAML uses generated .png names, not .svg names.

Change full/reversed/tiny variants together when refining the mark. The archived concept boards are under artifacts/design/math-solver-logo-2026-10-30/.
