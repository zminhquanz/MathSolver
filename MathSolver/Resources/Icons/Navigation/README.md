# Math Solver vector icons

Original application-owned geometry generated by `tools/branding/generate-navigation-icons.mjs`.
The SVGs and `Resources/Fonts/MathNavigationIcons.ttf` are generated from the same contours.
No Icons8 artwork or traced PNG previews are included.

- Shared 24×24 drawing grid. Original textbook/instrument topic symbols start at
  1.8-unit strokes with rounded terminals and joins; generated SVG and TTF contours
  share the same geometry. Open symbols receive optical sizing, not uniform bounding-box scaling.
- Keep x-bar, diagonal one-half, x-squared/radical, x-equality and bracketed matrix
  recognizable as textbook notation. Calculator, magnifier, set-square, clock and
  ruler provide familiar instrument silhouettes. Do not add logo/AI decoration to topics.
- Number Theory uses upright `12` and Fraction uses diagonal `½` (approved B concepts,
  2026-11-12). Keep their full localized tab names; educational heading notation is separate.
- Optical follow-up (2026-11-13): Measurement keeps a horizontal ruler with an 18-by-14
  body and three alternating ticks. Find X keeps a 5-by-5 variable inside a radius-7.5
  lens centered at (10,10), opening the counter without adding detail. Both retain the
  family's 1.8-unit design weight. Do not replace the paired mathematical meanings
  of Power/Root or Motion with a plain radical or clock from a catalogue.
- Rounded digits and variable x use sampled cubic centerlines in the generator.
  These are converted into the same filled SVG/native-font contours as straight lines.
  Renderer, glyph order and codepoints remain unchanged. Never hand-edit generated SVGs.
- `ActionIconCatalog`: action identity/aliases and legacy caption compatibility.
- `ActionIcon`: native button icon, 20 logical units, exact button text color.
- `ActionIconView`: decorative heading/overlay icon, normally 24 for navigation or 20 for actions.
- `MathNavigationCatalog`: existing math topics; keep these identities separate from action captions.
- Append glyphs; preserve existing PUA codepoints to avoid changing navigation artwork.

Rebuild with `node tools/branding/generate-navigation-icons.mjs` (no npm dependencies).
Audit with `node tools/branding/audit-navigation-icons.mjs`, then render the topic
symbols at 16, 20, 24, and 32 pixels in both light and dark themes using
`powershell -NoProfile -ExecutionPolicy Bypass -File tools/branding/render-navigation-preview.ps1`.
SVG files remain vector source assets; the font transports their outlines to native Windows/Android
renderers for tinting and density-aware rendering. It does not rasterize them at a fixed build-time size.

`MathNavigationIcon.Key` continues to attach math topic glyphs to native tabs, chooser entries
and compact selectors. Its imported-language-pack prefix compatibility is independent of action
caption cleanup; page headings and formulas are not rewritten. The icon font is not offered as
a text font in Settings.

Windows uses `NavigationFontImageSourceService` to preserve the requested 20/24 logical size
while drawing at the window's density. The Android sub-tab strip rasterizes the font at
device density in `MaterialSubTabStripHandler`; other font images use MAUI's renderer.
