# Math Solver vector icons

Original application-owned geometry generated by `tools/branding/generate-navigation-icons.mjs`.
The SVGs and `Resources/Fonts/MathNavigationIcons.ttf` are generated from the same contours.
No Icons8 artwork or traced PNG previews are included.

- Shared 24×24 drawing grid, typically 1.75-unit strokes with rounded ends.
- `ActionIconCatalog`: action identity/aliases and legacy caption compatibility.
- `ActionIcon`: native button icon, 20 logical units, exact button text color.
- `ActionIconView`: decorative heading/overlay icon, normally 24 for navigation or 20 for actions.
- `MathNavigationCatalog`: existing math topics; keep these identities separate from action captions.
- Append glyphs; preserve existing PUA codepoints to avoid changing navigation artwork.

Rebuild with `node tools/branding/generate-navigation-icons.mjs` (no npm dependencies).
SVG files remain vector source assets; the font transports their outlines to native Windows/Android
renderers for tinting and density-aware rendering. It does not rasterize them at a fixed build-time size.

`MathNavigationIcon.Key` continues to attach math topic glyphs to native tabs, chooser entries
and compact selectors. Its imported-language-pack prefix compatibility is independent of action
caption cleanup; page headings and formulas are not rewritten. The icon font is not offered as
a text font in Settings.

Windows uses `NavigationFontImageSourceService` to preserve the requested 20/24 logical size
while drawing at the window's density. Android uses MAUI's native font-image renderer.
