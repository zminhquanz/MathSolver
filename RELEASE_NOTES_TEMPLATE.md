# Math Solver v0.1.0 Beta

The first public preview of **Math Solver**, an offline-first mathematics learning and problem-solving application built with .NET MAUI.

> This is a beta release. Some features and layouts may still change before the first stable release.

## Highlights

- Basic arithmetic with integer and decimal modes
- Step-by-step fraction calculations
- Unknown-value equation solving
- High-precision quadratic equation solving
- Parabola graph rendering
- Plane and solid geometry calculators
- Reusable formula and diagram catalog
- Multiplication and division tables
- Light and dark themes
- Vietnamese and English localization
- Responsive layouts for desktop, laptop, tablet, and phone

## Downloads

Choose the correct package for your platform:

- **Windows x64:** `MathSolver-v0.1.0-beta.1-win-x64.zip`
- **Android:** `MathSolver-v0.1.0-beta.1-android.apk`

## Installation

### Windows

1. Download the Windows ZIP package.
2. Extract the archive.
3. Run `MathSolver.exe`.
4. If Windows displays a security warning for an unsigned preview build, review the publisher information before continuing.

### Android

1. Download the APK.
2. Allow installation from the browser or file manager when Android asks.
3. Install the APK.
4. Disable installation from unknown sources again after installation if you do not normally use it.

## Known Limitations

- This preview may not yet include signed store packages.
- Some responsive layouts may still require refinement on uncommon screen sizes.
- Platform-specific behavior may differ between Windows and Android.
- Additional geometry problems and calculation explanations are still planned.
